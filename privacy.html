Privacy policy

Last updated: 16 October 2026

Fakhro is a private tool, used only by its owner on YouTube channels they manage. This page explains what it does with the data it can reach through Google sign-in.

What it uses

Fakhro uses the YouTube API Services. With the permission given when signing in, it reads the signed-in channel's name, and creates, updates, starts, ends and deletes that channel's live broadcasts and stream keys. It does not read or change any other videos, comments, subscribers or personal information, and it uses no other Google services.

What it keeps

The only thing kept is the sign-in permission itself, stored privately on the owner's own server so that the tool can manage the live broadcasts without signing in each time. It is never shared, sold or sent to anyone else, and it is not used for advertising.

How to remove access

Access can be removed at any time on the Google account's permissions page: myaccount.google.com/connections. Removing it makes the stored permission useless at once.

Google and YouTube

By using Fakhro you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.
